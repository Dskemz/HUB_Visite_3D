Visite 3D

Navigue dans le viewer jusqu'à l'endroit voulu, oriente le regard (la vue 1re personne marche aussi), puis capture. Le POV apparaît aussitôt dans la visite, cliquable.

Passe le viewer en vue de dessus, puis :

· clic sur un trait de cotation → il se scinde à l'endroit cliqué, les cotes se recalculent seules ;
· clic sur une graduation → elle disparaît, les deux cotes fusionnent.

Aucun calcul, aucune saisie.
